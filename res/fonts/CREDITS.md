# Fonts

## Italianno Regular

- File: `Italianno-Regular.ttf`
- Used for: titles, HUD labels, narrative body, end screens
- License: SIL Open Font License (OFL)
- Source: Google Fonts / typographer credit as distributed with the OFL package

No second body font was required; readability is handled with larger sizes,
dark drop shadows, and parchment panels behind important text.
